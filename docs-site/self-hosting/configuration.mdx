<Warning>
  **Five values must be changed for any real deployment.** The bundled compose file ships loud
  `change-me` defaults so a laptop try-out works; they are not safe anywhere else.

  `TOPOS_PUBLIC_URL` · `TOPOS_WEB_AUTH_SECRET` · `TOPOS_INTERNAL_TOKEN` ·
  `TOPOS_PLANE_DB_PASSWORD` · `TOPOS_WEB_DB_PASSWORD`
</Warning>

## Compose-level

Set these in a `.env` beside `docker-compose.yml`, or in your host shell. Compose fans them out to
the right services.

| Variable | Required | Default | Controls |
|---|---|---|---|
| `TOPOS_PUBLIC_URL` | **behind a proxy** | *(empty — falls back to the request origin)* | The canonical public origin. Drives workspace addresses, the protocol card's API base, invite and verification links, the printed setup link, and the canonical-host redirect |
| `TOPOS_WEB_AUTH_SECRET` | **yes** | `change-me-…` | Session signing. **Minimum 32 characters** or the app refuses to start serving |
| `TOPOS_INTERNAL_TOKEN` | **yes** | `change-me-internal-token` | The app↔vault bearer. Fans out to both services; they must match |
| `TOPOS_PLANE_DB_PASSWORD` | **yes** | `plane` | Password for the `topos_plane` role — used both to create it and to connect |
| `TOPOS_WEB_DB_PASSWORD` | **yes** | `web` | Password for the `topos_web` role |
| `TOPOS_WORKSPACE_NAME` | no | `team` | The first workspace's address slug. `^[a-z0-9][a-z0-9-]*$`, max 100. Renameable in-product later |
| `TOPOS_SETUP_CODE` | no | *(freshly minted each boot while unclaimed)* | Presets the claim code for CI/IaC. **Minimum 16 characters** |
| `TOPOS_SETUP_LINK_FILE` | no | *(logs only)* | Also append the printed setup line to this path |
| `POSTGRES_USER` / `POSTGRES_PASSWORD` / `POSTGRES_DB` | no | `topos` / `topos` / `topos` | The bundled Postgres superuser and database name |

## The web app

| Variable | Required | Default | Controls |
|---|---|---|---|
| `DATABASE_URL` | **yes** | *(compose builds it)* | Connects as `topos_web`; owns schema `web`, reads `plane` read-only |
| `BETTER_AUTH_SECRET` | **yes** | *(from `TOPOS_WEB_AUTH_SECRET`)* | Session signing; minimum 32 characters |
| `BETTER_AUTH_URL` | **yes** | *(from `TOPOS_PUBLIC_URL`, else `http://localhost:3000`)* | The origin sessions are minted for |
| `PLANE_INTERNAL_URL` | **yes** | `http://plane:8787` | The vault, on the internal network |
| `PLANE_INTERNAL_TOKEN` | **yes** | *(from `TOPOS_INTERNAL_TOKEN`)* | The shared internal bearer |
| `APP_ENV` | no | `production` in the image | Arms production-tier belts, including the auth rate limiter |
| `TOPOS_WEB_RATELIMIT` | no | `on` | The `/api/v1` token bucket. **Set `off` with no reverse proxy** — it keys on the last `x-forwarded-for` hop, so proxy-less deployments share one bucket |
| `INSTALL_SH_PATH` | no | `/app/scripts/install.sh` in the image | The bytes served at `/install` and `/install.sh` |
| `BUILTIN_SKILL_DIR` | no | `../skills/topos` | Source for `/.well-known/agent-skills/…`. See the [known rough edge](/self-hosting/deploy#known-rough-edges) |
| `WEB_MIGRATIONS_DIR` | no | `<cwd>/drizzle`, then `<cwd>/web/drizzle` | Overrides the boot migrator's journal folder |
| `TOPOS_UPSTREAM_CHECK_MS` | no | `3600000` (hourly) | The upstream-provenance poll interval. `0` disables |
| `SENTRY_DSN` | no | *(disabled)* | Server-side error reporting only. No tracing, no cookies, no PII; token paths scrubbed |
| `TOPOS_GTM_CONTAINER_ID` | no | *(unset)* | Optional Google Tag Manager snippet, shape-fenced to `GTM-…`. The open-source default ships **zero** third-party script |
| `PORT` / `HOST` / `NODE_ENV` | no | `3000` / `0.0.0.0` / `production` | Node and the server binding |

## The vault

Every one is also a command-line flag — `topos-plane --help` is the live reference.

| Variable | Flag | Required | Default | Controls |
|---|---|---|---|---|
| `DATABASE_URL` | `--database-url` | **yes** | — | Connects as `topos_plane`. Append `?sslmode=require` for a networked database |
| `TOPOS_PLANE_BIND` | `--bind` | no | `0.0.0.0:8787` in the image | Listen address. **Must stay on an internal interface** |
| `TOPOS_PLANE_GIT_ROOT` | `--git-root` | yes | `/data/git` in the image | Per-workspace git object store |
| `TOPOS_PLANE_LARGE_ROOT` | `--large-root` | yes | `/data/large` in the image | Per-workspace large-object store |
| `TOPOS_PLANE_INTERNAL_TOKEN` | `--internal-token` | effectively yes | *(unset)* | Arms `/internal/v1`. **Unset means the entire lane answers 404** |
| `TOPOS_PLANE_GC_INTERVAL_SECS` | `--gc-interval-secs` | no | `300` | Storage maintenance cadence; first pass at startup. `0` disables with a warning |
| `TOPOS_PLANE_DB_MAX_CONNECTIONS` | — | no | 10 | Pool size |
| `TOPOS_PLANE_DB_ACQUIRE_TIMEOUT_SECS` | — | no | 30 | Pool acquire timeout |
| `TOPOS_PLANE_DB_STATEMENT_TIMEOUT_SECS` | — | no | off | Per-connection `statement_timeout` |
| `TOPOS_PLANE_DB_LOCK_TIMEOUT_SECS` | — | no | off | Per-connection `lock_timeout` |
| `TOPOS_PLANE_DB_IDLE_IN_TX_TIMEOUT_SECS` | — | no | `30` | `idle_in_transaction_session_timeout`. `0` disables |
| `RUST_LOG` | — | no | `info` | Log filter. JSON logs go to **stderr**; stdout is never touched |

## Runtime policy that is *not* an environment variable

Some things you might expect to be env knobs are deliberately in-product, so they are audited and
changeable without a redeploy. All are on **Settings → General**, owner-only:

| Setting | Default |
|---|---|
| Review gate (the workspace protection default) | off — publishes land directly |
| Staleness window | 7 days |
| Session approval | off |
| Session expiry | none |
| Registration (single-workspace installs) | invite-only |

## Client-side variables

These are read by the `topos` CLI on each machine, not by the server. See
[Install](/install#client-environment-variables) for the full list — most relevant here:

| Variable | Effect |
|---|---|
| `TOPOS_PLANE_URL` | The default server a bare workspace name resolves against. Point it at your own origin |
| `TOPOS_HOME` | The client state root — the way to run two installations against two servers |
| `TOPOS_DEBUG=1` | Print each error's full source chain to stderr |

## Retired — do not use

`PLANE_PUBLIC_URL` still appears in an example file but is **dead**. It was replaced by
`TOPOS_PUBLIC_URL` when the vault lost its public listener.
